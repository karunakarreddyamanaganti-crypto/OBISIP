# BMI Calculator

## Description
This is a simple Python project that calculates Body Mass Index (BMI).

## Features
- Takes user name as input
- Takes weight in kilograms
- Takes height in centimeters
- Calculates BMI
- Displays BMI category

## Technologies Used
- Python 3
